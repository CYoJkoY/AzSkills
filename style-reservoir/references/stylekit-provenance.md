## What AzSkills stores

AzSkills stores a compact local metadata projection of the 148 StyleKit styles in stylekit-catalog.json.

The catalog preserves source-facing fields needed for retrieval and provenance: names, descriptions, style type, category, tags, colors, keywords, compatibility information, source paths, and stable source URLs.

## What AzSkills does not vendor

AzSkills does not vendor StyleKit's Next.js application, npm packages, framework wrappers, MCP server, generated site assets, screenshots, preview images, tests, deployment configuration, or unrelated repository tooling.

The Style Reservoir is a design-reference catalog, not a mirror of the StyleKit application.

## Update policy

When refreshing the reservoir:
1. identify the exact StyleKit commit;
2. re-read the upstream metadata registry;
3. regenerate the 148-style catalog;
4. preserve source URLs pinned to the reviewed commit;
5. review additions/removals and field-shape changes;
6. update this provenance record;
7. run repository CI before advancing the integration.

Do not silently switch the catalog to a moving main URL for provenance-sensitive data.

## Selection boundary

Presence in the catalog does not mean automatic selection. The owning project design system and explicit user requirements remain higher priority. Selection is conditional on context and can fail closed when evidence is insufficient.

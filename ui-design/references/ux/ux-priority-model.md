# UX Priority Evaluation Model

## Purpose

Provide a consistent method for ranking UX problems during interface reviews.

## Evaluation Dimensions

### User Impact

Measure how much the problem affects user goals:

- Blocks task completion
- Causes confusion
- Increases unnecessary effort
- Reduces discoverability

### Frequency

Consider how often users encounter the issue:

- Every workflow
- Common workflow
- Rare edge case

### Recovery Cost

Evaluate the difficulty of recovering from the problem:

- Automatic recovery
- Simple user correction
- Data loss or workflow interruption

### Implementation Cost

Consider engineering effort:

- Small UI adjustment
- Component-level change
- Architectural change

## Recommendation Format

Each UX issue should include:

- Problem description
- User impact
- Frequency
- Suggested priority
- Implementation considerations

## Priority Rule

Prioritize improvements that significantly improve user goals with reasonable implementation complexity.

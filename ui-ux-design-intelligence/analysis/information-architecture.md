# Information Architecture Analysis

## Purpose

Evaluate whether an interface structure matches user goals instead of internal implementation structure.

## Review Dimensions

- User task clarity
- Navigation depth
- Feature grouping
- Information priority
- Progressive disclosure

## Common Issues

### Technical grouping

Avoid organizing around internal modules when users think in workflows.

### Hidden primary actions

Important actions should remain discoverable without requiring expert knowledge.

## Review Output

Include:

- Current structure
- User impact
- Recommended information hierarchy
- Implementation considerations

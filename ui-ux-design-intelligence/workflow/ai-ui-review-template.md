# AI UI Review Output Template

## Context

Describe:

- Product type
- Target platform
- User goal
- Current workflow

## User Goal Analysis

Explain whether the interface supports the intended task.

## Information Architecture

Review:

- Feature grouping
- Navigation structure
- Information priority
- Progressive disclosure

## Interaction Review

Check:

- User actions
- System feedback
- Loading states
- Error handling
- Recovery paths

## Visual Review

Analyze:

- Layout hierarchy
- Typography
- Spacing consistency
- Component consistency

## Accessibility Review

Consider:

- Keyboard navigation
- Focus behavior
- Contrast
- Text clarity

## Engineering Handoff

Provide:

- Recommended components
- Required states
- Data changes
- Implementation constraints

## Priority Summary

For each recommendation include:

- User impact
- Frequency
- Complexity
- Suggested priority

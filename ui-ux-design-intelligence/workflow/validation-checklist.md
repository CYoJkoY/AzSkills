# UI/UX Design Intelligence Validation Checklist

## Purpose

Verify that the skill structure, workflows, and outputs remain consistent before review or release.

## Skill Structure

Check:

- Entry point clearly defines purpose and scope
- Workflow documents have distinct responsibilities
- Related workflows avoid duplicated guidance
- Routing rules match available capabilities

## Content Quality

Check:

- Recommendations are based on user goals
- Observations are separated from proposals
- Suggestions include implementation considerations
- Platform constraints are considered

## Workflow Coverage

Verify coverage for:

- UX analysis
- Interaction review
- Design system audit
- Accessibility review
- Screenshot analysis
- Developer handoff
- Regression checking

## Output Quality

Every review result should include:

- Context
- Current behavior
- User impact
- Recommended improvement
- Implementation considerations
- Risk or trade-offs

## Integration Review

Confirm that the skill works with:

- Issue definition workflows
- Pull request reviews
- Feature planning
- Regression analysis

## Final Review Questions

- Can another agent discover when to use this skill?
- Can developers act on the generated recommendations?
- Are platform-specific differences preserved?
- Does the guidance avoid unnecessary redesign?

# UX Audit Process

## Step 1: Understand Context

Identify:

- User goals
- Target platform
- User expertise
- Main workflows

## Step 2: Analyze

Review:

- Information architecture
- Interaction flow
- Visual hierarchy
- Accessibility

## Step 3: Recommend

Provide:

- Priority level
- User impact
- Suggested solution
- Development considerations

## Step 4: Validate

Check:

- Consistency
- Edge cases
- Platform conventions
- Implementation feasibility

# UX Pattern Library

## Purpose

Provide reusable UX pattern references for reviewing and designing interfaces across common application categories.

## Pattern Structure

Each pattern should document:

- User Goal
- Context of Use
- Interaction Model
- Expected States
- Accessibility Requirements
- Platform Considerations
- Implementation Notes

## Desktop Application Patterns

### Settings and Preferences

Review:

- Clear grouping of configuration options
- Predictable navigation
- Search for large settings surfaces
- Safe confirmation for destructive changes

### Productivity Workflow

Review:

- Keyboard accessibility
- Short paths for frequent actions
- Persistent user context
- Non-blocking feedback

## Browser Extension Patterns

### Popup Interface

Review:

- Limited viewport usage
- Primary action visibility
- Permission explanation
- Fast completion of common tasks

### Extension Management

Review:

- Sync state visibility
- Missing permission handling
- Recovery paths

## Developer Tool Patterns

### High Density Interface

Review:

- Information hierarchy
- Search and filtering
- Expert shortcuts
- Progressive disclosure

### Debugging Workflow

Review:

- Clear diagnostics
- Actionable errors
- Context preservation

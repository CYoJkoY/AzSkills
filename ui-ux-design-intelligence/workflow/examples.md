# UI/UX Design Intelligence Examples

## Purpose

Provide practical examples of how the skill should be applied.

## Example 1: UI Regression Review

Input:

A settings page layout changed after adding a new configuration section.

Process:

1. Analyze user workflow impact
2. Check information hierarchy
3. Review component consistency
4. Identify regression risks

Output:

- Current issue
- User impact
- Recommended improvement
- Implementation notes

## Example 2: Screenshot Analysis

Input:

A screenshot of a desktop application window.

Process:

1. Identify primary user goal
2. Analyze visual hierarchy
3. Check interaction states that require validation
4. Compare against platform patterns

Output:

- Observed patterns
- Potential UX issues
- Validation requirements

## Example 3: Feature Planning

Input:

A request to add a new user-facing feature.

Process:

1. Define user goal
2. Map workflow
3. Identify required states
4. Prepare developer handoff

Output:

- UX requirements
- Component considerations
- Acceptance criteria
- Regression risks

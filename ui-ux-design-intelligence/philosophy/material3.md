# Material 3 Adaptation Principles

## Purpose

Extract Google Material 3 ideas into reusable UX reasoning rules instead of copying visual styles.

## Core Principles

### User-Centered Surfaces

Interfaces should organize information around user tasks, not around technical structure.

### State Visibility

Every important action should expose:

- Current state
- Progress
- Success result
- Failure reason
- Recovery action

### Adaptive Components

Components should adapt to:

- Platform conventions
- Screen size
- Input method
- User expertise

## AzSkills Localization

Material principles should be adapted for:

- Windows desktop applications
- Browser extensions
- Developer tools
- Open-source utilities

Avoid blindly applying mobile-first patterns to productivity software.

# UI/UX Review Checklist

## Structure

- Is the user goal obvious?
- Are important actions easy to find?
- Are settings grouped logically?

## Interaction

- Are states visible?
- Are errors actionable?
- Are destructive actions protected?

## Visual

- Is spacing consistent?
- Is typography readable?
- Are components reused consistently?

## Accessibility

- Keyboard support exists
- Contrast is sufficient
- Focus state is visible

## Developer Handoff

Recommendations should include:

- Component suggestions
- Data/state considerations
- Implementation constraints
- Testing scenarios

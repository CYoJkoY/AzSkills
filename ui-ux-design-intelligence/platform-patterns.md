# Platform UX Patterns

## Windows Desktop

Consider:

- Native window behavior
- Dense productivity workflows
- Keyboard-first operations
- System integration

## Browser Extensions

Consider:

- Limited popup space
- Permission transparency
- Fast task completion
- Browser conventions

## Developer Tools

Consider:

- Information density
- Debugging workflows
- Advanced configuration visibility
- Technical user expectations

## Localization

Avoid direct translation of UI concepts. Adapt terminology and interaction patterns for different user groups.

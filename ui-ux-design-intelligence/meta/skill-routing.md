# Skill Routing

## Purpose

Define when the UI/UX design intelligence skill should be used and how it cooperates with other AzSkills capabilities.

## Use This Skill When

- Reviewing interface quality
- Improving existing UI/UX flows
- Designing new product features
- Analyzing screenshots or mockups
- Preparing product design specifications
- Reviewing usability issues in pull requests

## Do Not Replace Other Skills

This skill focuses on design decisions, not implementation details.

- UI/UX Intelligence: why and what should be improved
- Architecture Skills: how the system should be structured
- Coding Skills: how the implementation should be written

## Standard Flow

User Goal → UX Analysis → Design Recommendation → Engineering Handoff

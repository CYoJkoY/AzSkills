# Design Principles

## 1. User Intent First

Every interface decision should start from user goals, not component appearance.

## 2. Clear Information Hierarchy

Prioritize:

- Primary actions
- Important status information
- Frequent workflows
- Advanced configuration

## 3. Consistent Mental Models

Controls should behave predictably across the product.

## 4. Immediate Feedback

Actions should provide:

- Progress indication
- Success confirmation
- Error explanation
- Recovery path

## 5. Accessibility

Consider:

- Keyboard navigation
- Contrast
- Text clarity
- Screen reader compatibility
- Reduced motion preferences

## 6. Localized Product Thinking

Design recommendations should consider platform conventions and user expectations rather than applying a single global style.

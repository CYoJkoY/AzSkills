# AzSkills Workflow Integration

## Role

The UI/UX design intelligence skill provides the product design layer inside AzSkills.

## Development Lifecycle

```
Requirement
    ↓
UX Analysis
    ↓
Issue Definition
    ↓
Technical Design
    ↓
Implementation
    ↓
UX Review
```

## GitHub Workflow Support

Use UX analysis to improve:

- Issue descriptions
- Feature specifications
- Pull request reviews
- Regression checks

## Review Focus

- Does the implementation preserve the user goal?
- Are interaction states complete?
- Is the design consistent with platform expectations?

# Browser Extension UX Pattern

## Constraints

Browser extensions operate in limited spaces and require clear trust boundaries.

## Popup Design

Prioritize:

- Immediate task completion
- Current status visibility
- Clear next action

## Permissions

Explain:

- Why permission is needed
- What data is accessed
- How users can control it

## Sync Features

Expose:

- Sync status
- Last operation
- Error cause
- Recovery path

# Settings Page UX Pattern

## Goal

Help users configure software without overwhelming them.

## Structure

Prefer grouping by user intent:

- General
- Appearance
- Privacy
- Sync
- Advanced

## Configuration Item

Each setting should communicate:

1. Name
2. Purpose
3. Current value
4. Available action
5. Result or feedback

## Complexity Management

Use progressive disclosure:

Basic options first.

Advanced options should remain discoverable but separated from common workflows.

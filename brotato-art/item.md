# Item Module

Use this module for passive items, relics, consumables, equipment icons, upgrade icons, and collectible objects.

## Icon Principle

The item must be understandable at thumbnail size without text. Use one dominant central object or symbol and a small number of supporting elements.

## Construction Order

1. Identify the single semantic idea.
2. Build a strong central silhouette.
3. Add one secondary shape if needed.
4. Apply limited color grouping.
5. Add minimal shadow and highlight blocks.
6. Validate recognition at small size.

## Composition

Fill the icon sufficiently to remain readable, but preserve a small safety margin around the outer contour. Avoid decorative frames unless the game UI explicitly requires one.

## Symbols

Simple symbols such as stars, arrows, crystals, gears, hearts, eyes, runes, coins, or elemental marks are acceptable. Keep them chunky and avoid thin glyph-like linework.

## Prompt Skeleton

> [Item concept], single dominant central object, strong compact silhouette, simple rounded geometry, bold black outer contour, clean saturated flat colors, limited palette, one or two hard-edged cartoon shadow blocks, minimal highlight, instantly readable game item icon, low-detail 2D indie game asset, transparent background.
